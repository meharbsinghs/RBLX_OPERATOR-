/features

The engine is fixed and generic. The design is data. The prompt is the interface.

Game-is-data

Balance, rosters, economy, map, lighting, UI tokens and audio identity all live in one generated spec. Swap it, get a different game.

Server-authoritative

Hitscan, damage, economy validated server-side. Anti-cheat samples movement, rejects impossible shots, probes wall-clips.

Craft layer

Sound identity per game (ambience, music tension curve, signature SFX), atmosphere + lighting mood, story hooks — Michael’s Zombies caliber.

Waypoint AI

No NavMesh. Zone-center waypoint graphs with LOS shortcuts and barricade targeting work on any generated map.

Batched networking

Hordes ride one compressed remote at config.net.enemyBatchHz; kills carry local death VFX with zero extra traffic.

Self-testing

_G.__TESTING = true spawns rounds, fires the hitscan engine, drives the shop, prints machine-parseable PASS/FAIL.

Meshy assets

Text-to-3D for enemies, props and maps — auto-uploaded to Roblox via Open Cloud as live rbxassetid:// links.

Hot-fix loop

Playtest crashes are parsed, mapped to repo files and patched by the Operator automatically.

Free-tier friendly

Zero keys run everything. DeepSeek, Meshy, Open Cloud and Operator are drop-in upgrades; every failure degrades gracefully.
