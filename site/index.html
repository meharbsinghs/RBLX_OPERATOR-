❯ every prompt ships a full game

      

        Not a demo. Not a shooting gallery of gray boxes. Each prompt produces a
        complete package — the same systems a commercial Roblox studio would
        build by hand.
      

      

        
01
Map & world
Procedural layout with hand-pinned props, zones, doors and a waypoint AI graph.

        
02
Lighting & atmosphere
Mood profile per game — storm, neon, dusk, horror — painted into Studio before you press Play.

        
03
Economy
Points, perks, mystery box, pack-a-punch, wall buys — balanced to fund progression.

        
04
Enemies & AI
Up to 6 enemy types, escalating rounds, boss waves, waypoint pathing — no NavMesh needed.

        
05
Weapons & feel
Distinct weapon roles with spring-physics viewmodel: sway, kick, ADS, reload, bob.

        
06
Sound identity
Ambience, a music tension curve per round state, and signature SFX — every game sounds like itself.

        
07
UI & HUD
Data-driven interface with theme tokens that match the game's identity.

        
08
Anti-cheat & netcode
Server-authoritative everything. Batched compressed networking for hordes.

        
09
3D assets
Meshy text-to-3D for enemies, props and maps — injected as live asset ids via Open Cloud.

❯ install

      

        A terminal CLI built on top of opencode — the open-source AI
        coding agent. No accounts, no keys, no .exe. Node 18+ and Roblox Studio
        are the only prerequisites. Windows, macOS and Linux.
      


      

        

          QUICKEST — DOWNLOAD
          
Get the rblx CLI

          
Download the whole engine as a zip, run setup.bat — done.

          

            rblx-operator-cli.zip → setup.bat
            download
          

          

            rblx doctor
            
          

          
Verifies opencode, Rojo, Studio and keys in one screen. Needs Node 18+.

        


        

          FIRST GAME
          
Design & ship

          
The rblx-designer agent designs the whole game; the engine compiles it.

          

            rblx design "a dark zombie survival in a cursed mall, 10 waves"
            
          

          

            Zero keys: rblx newgame --offline "<idea>" derives offline.
            Build with rblx build → playtest in Studio.
          

        


        

          DEVELOPERS — SOURCE
          
Install from source

          
Clone the repo and link the CLI globally (npm publishing is on the roadmap).

          

            git clone … && npm install -g .
            
          

          
Now rblx is on your PATH. Run opencode auth login once for the design brain.

        


        

          STUDIO — PLUGIN
          
The Craft plugin

          
Devlog console, one-click playtest, lighting moods, Meshy injection — inside Roblox Studio.

          

            RBLXOperatorCraft.luau → Studio
            download
          

          
Drag the .luau into Studio → Plugins → install. rblx plugin prints build steps.
