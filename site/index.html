❯ every prompt ships a full game

Not a demo. Not a shooting gallery of gray boxes. Each prompt produces a complete package — the same systems a commercial Roblox studio would build by hand.

01

Map & world

Procedural layout with hand-pinned props, zones, doors and a waypoint AI graph.

02

Lighting & atmosphere

Mood profile per game — storm, neon, dusk, horror — painted into Studio before you press Play.

03

Economy

Points, perks, mystery box, pack-a-punch, wall buys — balanced to fund progression.

04

Enemies & AI

Up to 6 enemy types, escalating rounds, boss waves, waypoint pathing — no NavMesh needed.

05

Weapons & feel

Distinct weapon roles with spring-physics viewmodel: sway, kick, ADS, reload, bob.

06

Sound identity

Ambience, a music tension curve per round state, and signature SFX — every game sounds like itself.

07

UI & HUD

Data-driven interface with theme tokens that match the game's identity.

08

Anti-cheat & netcode

Server-authoritative everything. Batched compressed networking for hordes.

09

3D assets

Meshy text-to-3D for enemies, props and maps — injected as live asset ids via Open Cloud.

❯ built like commercial software

The runtime is a fixed, typed, server-authoritative engine. The game is data. The prompt is the interface.

game_is_data

Game-is-data

Balance, rosters, economy, map, lighting, UI tokens and audio live in one generated spec. Swap it — get a different game.

strict_luau

--!strict everywhere

Every file typed, every remote declared, every number clamped. The gate runs on CI before anything ships.

craft_layer

Craft layer

Sound identity, music tension curves, lighting moods and story hooks — the polish that separates real games from prototypes.

waypoint_ai

Waypoint AI

No NavMesh. Zone-center waypoint graphs with LOS shortcuts and barricade targeting — works on any generated map.

batched_net

Batched networking

Hordes ride one compressed remote; kills carry local death VFX with zero extra traffic.

self_testing

Self-testing

_G.__TESTING spawns rounds, fires the hitscan engine, drives the shop — machine-parseable PASS/FAIL on CI.

meshy_assets

Meshy 3D

Text-to-3D for enemies, props and maps — auto-uploaded to Roblox via Open Cloud as live rbxassetid:// links.

hot_fix

Hot-fix loop

Playtest crashes are parsed, mapped to repo files and patched by the Operator automatically.

unbounded

Unbounded genres

Wave, extraction, defense, arena, boss-rush ship today. newtype scaffolds obby, tycoon, racing, RPG packs.
