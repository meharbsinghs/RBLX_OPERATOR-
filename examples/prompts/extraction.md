# Example prompt — extraction shooter

> Copy this into `node pipeline/bridge.js newgame "<prompt>"`, or paste it as the
> user message in any AI chat whose system prompt is `pipeline/system_prompt.md`
> and import the JSON with `--spec`.

```
A tense, objective-driven extraction shooter set in a flooded harbor district
at night. You have a limited number of raids (5 waves) — survive each wave,
loot the zone, and extract after the final wave or die trying.

Mood: industrial night — wet concrete, sodium lamps, deep blue shadows with a
warm amber rim light. Style: grunge with a cold blue palette. UI: amber alert
tokens on gunmetal panels.

Players start geared (generous starting cash, 1500+) so the first raid is a
real run, not a grind. A heavily armored boss appears every 2 rounds, guarding
progress. Door costs are high — pushing deep into the harbor is a bet.

Economy: kills pay well but the stakes come from extract-or-lose pacing: boss
pressure builds so the final wave is chaos. Pack-a-punch is expensive; perks
are rare and powerful. Weapons: suppressed starter pistol, an SMG, a marksman
rifle, and a heavy shotgun for close quarters; the wonder weapon is a prototype
railgun from the loot boxes.

Win condition: extract on wave 5. Balance so most groups feel the win is earned,
not guaranteed.
```
